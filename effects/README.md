## Size and expression categories

Use manufacturer unit dimensions, **W×D×H in millimetres**, not packaging dimensions. The defined size bins are:

| Bin | Width and depth test |
|---|---|
| Compact | Width ≤200 mm **and** depth ≤140 mm |
| Medium | Width ≤300 mm and depth ≤200 mm, but not compact |
| Large | Exceeds the medium width or depth limit |
| Unknown | Width or depth has not been verified |

Do not rotate a device to make it pass the filter. Plug, cable and expression-pedal clearance are additional. Within comparison pages, distinguish **built-in expression**, **external expression only**, and **neither/unverified**. An expression socket is not an included pedal.

## Required comparison fields

The complete record covers expression; separate knob/footswitch/button counts; used/new **IDR** prices; simultaneous blocks and category choices; I/O; factory/user presets; synth/acoustic functions; dimensions/weight; power/battery/USB operation; IR/NAM/capture formats; editor platforms; and **screen size, monochrome/color and touchscreen support**.

Extra fields include headphones, DI/phantom power, USB audio/reamp, MIDI, scenes, routing, bypass/trails, looper, rhythms, firmware context and special pickup/cable requirements. See [METHODOLOGY.md](METHODOLOGY.md) for the definitions that make those figures comparable.

`?` means **unverified**, not No. Display diagonal cannot be guessed from product photos. Color, screen technology and touch capability are independent fields. Foreign prices can be retained as source evidence, but any IDR conversion needs a verified dated rate and an explicit **FX estimate** label. A converted international offer is not an Indonesian delivered price.
