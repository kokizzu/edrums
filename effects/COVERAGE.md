The scope is **not yet every guitar, bass or vocal effects pedal ever manufactured**. Current coverage prioritises multi-effects and a selection of dedicated effects. ## Highest-priority unfinished fields

1. **Used and Indonesian prices:** obtain identifiable seller offers with model/revision, condition, date, market and included accessories. Many current rows have only a new-price observation or no dependable price. Indexed old listings need a current availability check. Do not turn a single offer into a market range.
2. **Effect lists:** transcribe firmware-specific algorithms by category, including amps, cabs, acoustic simulators and synth types. Distinguish total library, installed library, simultaneously active blocks and DSP limits.
3. **Control counts and physical specifications:** finish the remaining rotary/button counts, port details and missing manufacturer dimensions. MG-101, MG-400, Matribox II Pro and Zoom V3 currently lack a verified full dimensional record in this catalogue.
4. **Power and software:** finish polarity/current, USB operation versus charging, mobile editor versus mobile audio, current supported OS versions, and any native Linux support. No Linux-editor compatibility has been established here merely from USB class compliance.
5. **Firmware conflicts:** resolve TONEX ONE's 20-versus-30 preset claim; MG-50Li's conflicting factory/user splits and factory model counts; Matribox II Pro MIDI-output claims; GP-100 drum count. Preserve contradictory evidence until a dated manual/release note resolves it.

## How to add a record

Copy this checklist; every non-unknown fact needs a supporting primary technical source or a dated price source.

```text
Brand / exact model / hardware revision:
Instrument category / subtype / current or discontinued evidence:
Research date / firmware context:
Built-in expression / toe switch / external expression sockets:
Rotary controls / main footswitches / separate buttons / other switches:
Dimensions W x D x H (mm) / maximum pedal height / weight:
Used offers: currency, price, market, condition, date, URL:
New offers: currency, price, market, availability, date, URL:
Simultaneous blocks / DSP limits / routing:
Categories and choices per category / amp / cabinet counts:
Factory presets / total editable memory / dedicated user memory:
Synth type / acoustic simulator vs amp vs body IR:
Inputs / outputs / headphones / aux / loops / MIDI / USB:
Mic preamp / phantom voltage / harmony chord-detection input:
Power voltage / polarity / current type / batteries / USB operation:
IR import, slots, sample length and supported formats:
Native NAM architectures / conversion workflow / proprietary captures:
Editor OS / librarian OS / updater OS / mobile adapter requirements:
USB audio channels / sample rates / loopback / reamp:
Looper / rhythms / scenes / bypass / trails / switching gap:
Special pickup, cable, account, licence or expansion requirements:
Primary sources / price sources / unresolved conflicts:
```

Do not replace `?` with No just to complete the table. Do not count a processor as fully researched because a manufacturer landing page exists. No automatic scheduled maintenance is configured; this repository is a dated research snapshot.
