# edrums

Electronic drum kit comparison focused on kits with:

- snare size >= 10 inches
- at least one tom >= 10 inches
- non-rubber tom pads only (mesh, TCS, or acoustic-style shell pads)

Rubber kick pads are allowed because the filter is about toms.

## Legend

- `Sn` = snare size in inches.
- `HH` = hi-hat type.
- `Ctrl` = controller pedal.
- `Stand` = stand-mounted hi-hat.
- `Dig` = digital hi-hat or digital ride.
- `Ride`: `2` = dual-zone, `3` = triple-zone, `3/360` = triple-zone 360-degree style triggering.
- `Cym`: `H` = hi-hat, `C` = crash, `R` = ride.
- `Kick`: `T` = tower/pad, `Sh` = shell kick, `R` = rubber kick pad.
- `5T` = Roland KD-10 5-inch kick pad.
- `7.5T` = Yamaha KP90 7.5-inch kick pad.
- `12T*` = Roland KD-12; 12-inch pad model, about 7.5-inch playing surface.
- `3x10*` on TD-17KVX2 = 10-inch outer pad size, with smaller playing area.
- `14D` = 14-inch digital snare.
- `14D+` = newer Roland PD-14DSX digital snare.
- `n/d` = not reliably documented.

## Notes

- Donner DED-200 MAX specs vary by listing: official/current pages commonly list 450 sounds and 31 kits, while some comparison material lists 480 sounds and a 6-inch rubber kick.
- Donner DED-500 kick size is marked with a dagger because some regional listings differ; Indonesian listings commonly show 7.5-inch mesh kick.
- Donner BEAT ride is marked `2?` because listings differ between marketing copy and spec tables.
- Alesis Strata series uses `370 pieces` instead of a normal voice count because Alesis describes the library as kit pieces, articulations, and samples rather than a simple voice list.
- Yamaha DTX6/DTX8 rows show both older module specs and newer kit/firmware listing style where sources differ.
- Prices are rough and should be rechecked for local used/new markets.
