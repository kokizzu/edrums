Electronic drum kit comparison focused on kits with:

- snare size >= 10 inches
- at least one tom >= 10 inches
- non-rubber tom pads only (mesh, TCS, or acoustic-style shell pads)

Rubber kick pads are allowed because the filter is about toms.

## Legend

- `Sn` = snare size in inches.
- `HH` = hi-hat type.
- `Ctrl` = controller pedal.
- `Stand` = stand-mounted hi-hat.
- `Dig` = digital hi-hat or digital ride.
- `Ride`: `2` = dual-zone, `3` = triple-zone, `3/360` = triple-zone 360-degree style triggering.
- `Cym`: `H` = hi-hat, `C` = crash, `R` = ride.
- `Kick`: `T` = tower/pad, `Sh` = shell kick, `R` = rubber kick pad.
- `5T` = Roland KD-10 5-inch kick pad.
- `7.5T` = Yamaha KP90 7.5-inch kick pad.
- `KD-9` = Roland KD-9 cloth-head kick pad.
- `12T*` = Roland KD-12; 12-inch pad model, about 7.5-inch playing surface.
- `3x10*` on TD-17KVX2 = 10-inch outer pad size, with smaller playing area.
- `14D` = 14-inch digital snare.
- `14D+` = newer Roland PD-14DSX digital snare.
- `n/d` = not reliably documented.

## Notes

- Pending rows should only be promoted into the confirmed table after all missing fields are verified, preferably from an official website or a clear retailer specification sheet.
- Excluded / not promoted by brand:
  - Alesis: Debut, Turbo Mesh, Nitro Mesh, Nitro Max, Nitro Pro, Nitro Pro XL, Nitro Ultimate, Surge Mesh, Command Mesh, and Strike MultiPad are not in the confirmed table because they fail the snare/tom size filter, lack a 10-inch tom, or are not full kits. Nitro Pro XL and Nitro Ultimate have 10-inch snares but only 8-inch toms.
  - Aroma: TDX-N1, TDX-10, TDX-16/16S, TDX-18/18S/18II/18-8S, TDX-22/22S/22II, and TDX-25/25S/25II are excluded because official/manual/retailer specs show 7-10 inch snares and 6-8 inch toms, below the tom-size filter.
  - Avatar / HXW: SD61-2 is excluded because of rubber toms; SD61-4, SD61-5, and SD61-6 are excluded because their snare/tom pads are below the size filter. Avatar A51 appears to meet the physical filter but is not promoted until specs are verified from an official or clearer source.
  - Beatevr: Evolve / Starter Kit is not added yet because no reliable snare/tom size specification was found.
  - Donner: smaller DED-series models such as DED-70, DED-80, DED-80P, DED-95, DED-100, DED-200, DED-200 Lite, DED-300X, and DED-400 are not promoted because they fail the snare/tom size filter or lack a verified 10-inch tom. DED-300X has a 10-inch snare, but official Donner specs list 8-inch toms.
  - E-Force: F-10/F10, EF1/EF2/EF5/EF6/EF7, and STOMP/Storm are not added yet because reliable snare/tom size specs were not found; F10/F10S module-only listings are excluded because they are not full kits.
  - Hampback: ACE-320 and MK-1S Pro are excluded because their snare/toms are below the size filter; MK-0 / MK-0 Plus are not promoted because pad-size specs are incomplete or entry-level; ACE-360 has conflicting tom-size listings; MK-5L Pro, MK-7X, and ACE-970 appear to meet the physical filter but are not promoted until accepted/verified sources are added.
  - Kyre: Series 2.0 is not added yet because pad-size specs were not reliably documented in the checked listings; Series 1.5 is promoted from the Artech comparison specs.
  - Lemon: T-300, T-300SE, and T-300SE Pro are excluded because they have a 10-inch snare but only 8-inch toms.
  - Medeli: MZ520 is excluded because the snare is below the size filter; MZ528 and MZ537 are excluded because the toms are below the 10-inch tom filter.
  - Nokku: NK300/XD300 is excluded because its snare/toms are below the size filter; MP5 is excluded because it is a multipad/module rather than a full e-drum kit. XD460/NK460 and XD2000/NK2000 are promoted because price, pad specs, kits, and voices are verified. XD460 Traveller remains pending because it passes the physical filter but still lacks fully verified voices/sounds.
  - NUX: smaller DM-series models such as DM-1, DM-210/210X, DM-7, and DM-7X are excluded because they fail the snare/tom size filter; DM-7X has a 10-inch snare but only 8-inch toms. DM-310 and DM-310H are promoted because official NUX specs confirm one 10-inch tom and complete kit/voice details.
  - Pearl: eRoadshow / ERS1000 is excluded because it has an 8-inch snare and 6.5-inch toms.
  - Roland: compact/entry kits such as TD-1, TD-02, TD-07, TD-07KV, TD-25K, and many non-KVX/KV compact variants are not promoted because they fail the size filter or use smaller tom pads; TD-25KV is promoted because it has a 10-inch PDX-100 floor tom; multipads are excluded because they are not full kits.
  - Soundking: SD100, SD10M-SP1/SP2, SD220, SD300, SD310, SKD350, and SKD360 are excluded because they fail the snare/tom size filter or use rubber tom/snare pads. SD600 remains pending until price is verified.
  - Yamaha: DTX402/432/452 and smaller DTX6 variants such as DTX6K-X / DTX6K2-X / DTX6K3-X are not promoted because they fail the snare/tom size filter or lack a 10-inch tom.
- Kyre Series 1.0 has rubber cymbals, but it passes the physical-pad filter because the filter only excludes rubber toms.
- Donner DED-200 MAX specs vary by listing: official/current pages commonly list 450 sounds and 31 kits, while some comparison material lists 480 sounds and a 6-inch rubber kick.
- Donner DED-500 kick size is marked with a dagger because some regional listings differ; Indonesian listings commonly show 7.5-inch mesh kick.
- Alesis Strata series uses `370 pieces` instead of a normal voice count because Alesis describes the library as kit pieces, articulations, and samples rather than a simple voice list.
- Yamaha DTX6/DTX8 rows show both older module specs and newer kit/firmware listing style where sources differ.
- Prices are rough and should be rechecked for local used/new markets.
